## 🚀 使用指南

### 如何使用重构后的代码

#### 1. 复制到项目中
```bash
# 复制前端组件
cp -r refactored/frontend/components/* src/components/

# 复制 Composables
cp -r refactored/frontend/composables/* src/composables/

# 复制后端服务
cp -r refactored/backend/services/* app/services/
```

#### 2. 安装依赖
```bash
# 前端依赖（如果有新增）
cd financial-analysis-admin
pnpm install

# 后端依赖（如果有新增）
cd financial-analysis-api
pip install -r requirements.txt
```

#### 3. 运行测试
```bash
# 前端测试
pnpm test

# 后端测试
pytest
```
